\# ORSPEX Favicon Generator



A free, private, browser-based favicon generator.



Upload any image → get favicon.ico, PNG variants, and site.webmanifest — ready for any website.



\*\*Runs entirely in your browser.\*\* No uploads. No signup. No tracking.



\## Live



https://orpexexitus-maker.github.io/orspex-favicon-generator/



\## Usage



1\. Open the link above

2\. Drag an image into the drop zone

3\. Click "Download all (.zip)"

4\. Extract into your website's root folder



\## Tech



Pure HTML + CSS + JS. Single file. No build step.
